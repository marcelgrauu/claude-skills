# Claude Code Skills — by Marcel Grau

5 skills for content creators. Hook writing, cinematic AI prompts, reel scripts, captions, and motion graphics. Free. Installed in 30 seconds.

---

## Install all 5 at once

```bash
curl -o ~/.claude/skills/viral-hook-creator.md https://raw.githubusercontent.com/marcelgrauu/claude-skills/main/01-viral-hook-creator.md && \
curl -o ~/.claude/skills/higgsfield-cinematic.md https://raw.githubusercontent.com/marcelgrauu/claude-skills/main/02-higgsfield-cinematic.md && \
curl -o ~/.claude/skills/reels-scripting.md https://raw.githubusercontent.com/marcelgrauu/claude-skills/main/03-reels-scripting.md && \
curl -o ~/.claude/skills/copywriting.md https://raw.githubusercontent.com/marcelgrauu/claude-skills/main/04-copywriting.md && \
curl -o ~/.claude/skills/remotion-liquid-glass.md https://raw.githubusercontent.com/marcelgrauu/claude-skills/main/05-remotion-liquid-glass.md
```

Restart Claude Code after running the command.

---

## The 5 skills

| # | Skill | Command | What it does |
|---|-------|---------|--------------|
| 01 | Viral Hook Creator | `/viral-hook-creator` | 6 hook variations — number-led, contrarian, transformation, authority, admission, future shock |
| 02 | Cinematic AI Prompting | `/higgsfield-cinematic` | One-line idea → production-grade Seedance prompt with camera, lighting, and hook framework |
| 03 | Reels Scripting | `/reels-scripting` | Full 60s reel script with hook, problem, revelation, solution, CTA + timestamps |
| 04 | Copywriting Generator | `/copywriting` | Instagram captions, launch posts, hooks, CTAs and ad copy in high-converting structure |
| 05 | Remotion Liquid Glass | `/remotion-liquid-glass` | Apple-style Liquid Glass motion graphics in Remotion — glass cards, gradients, spring animations |

---

## How to install individually

**Windows:** open Git Bash or WSL and run the commands above. Or copy the `.md` file manually to `C:\Users\YourName\.claude\skills\`
